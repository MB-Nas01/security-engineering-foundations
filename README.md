
# Security Engineering Foundations

A six-week practical learning journey focused on developing foundational security engineering skills.

## Objectives

- Understand information security fundamentals.
- Investigate Linux systems and networks.
- Understand web applications and APIs.
- Identify common security vulnerabilities.
- Perform basic security code reviews.
- Understand vulnerability remediation and testing.

## Learning Approach

Understand → Practise → Explain → Document → Assess

## Course Structure

| Week | Focus |
|---|---|
| 1 | Security Fundamentals |
| 2 | Web Applications and APIs |
| 3 | Authentication and Access Control |
| 4 | Common Web Vulnerabilities |
| 5 | Secure Code Review and Remediation |
| 6 | Independent Security Assessment |

## Tools

- Kali Linux (WSL2)
- Visual Studio Code
- Git and GitHub
- Wireshark
- Burp Suite Community Edition
- OWASP learning resources

## Documentation

Practical exercises, investigation notes, findings and lessons learned will be documented throughout the course.

## Disclaimer

All security testing and demonstrations are performed in authorised environments, personal labs or deliberately vulnerable applications.
